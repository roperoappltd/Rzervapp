# Register / sign-in form translation fix

## Why it was not translated
The form labels and error messages in `app/users/forms.py` (and one in `app/models/usermodel.py`) were plain strings, not wrapped in `_l()` / `_()`. Babel never extracted them, so no French existed for them. The country list also came from English-only `country.name`.

## What changed
- `app/users/forms.py`: labels, button text, gender options, validation messages wrapped for translation. LoginForm, RegistrationForm, UpdateAccountForm (picture/update/error messages), ResendVerificationForm, RequestResetForm, ResetPasswordForm, DeleteAccountForm.
- Country dropdown is now built per request in the visitor's language (pycountry has French names) and sorted by name. Stored values (CI, FR, ...) are unchanged.
- New message "Passwords do not match." replaces the raw "Field must be equal to password."
- `app/models/usermodel.py`: under-18 message wrapped, plus `from flask_babel import gettext as _`.
- `messages.po` / `messages.mo`: 25 new strings translated. This file replaces the one from the earlier zip (it contains all 173 earlier strings too). The earlier messages.po had a stray empty header block near line 3036 that I have removed here. Use this version, not the earlier one.

Tested in French and English: labels, country list, empty submit, under-18 date of birth, taken username and email, mismatched passwords.

## Steps (PowerShell, project root, venv active)
1. Apply the code changes. `forms.py` may differ from my copy if you edited it since 10 Oct, so use the diff first:

       git status
       git apply --ignore-whitespace --check 23-10-26-forms-changes.diff
       git apply --ignore-whitespace 23-10-26-forms-changes.diff

   If the check fails, tell me, or copy the two files from `app/` in this folder over yours after comparing with `git diff`.

2. Copy `fr/LC_MESSAGES/messages.po` and `messages.mo` into `app\translations\fr\LC_MESSAGES\` (overwrite).

3. Recompile (same result as the supplied .mo):

       pybabel compile -d app/translations --statistics

4. Restart the Flask server (Python files changed), switch the site to French, hard refresh (Ctrl+F5), open `/register`. Check: field labels, country list, submit empty form, DOB under 18, an existing username, mismatched passwords. Then `/login`.

5. Commit and push:

       git add app/users/forms.py app/models/usermodel.py app/translations/fr/LC_MESSAGES/messages.po app/translations/fr/LC_MESSAGES/messages.mo
       git commit -m "Translate sign-up, login and account forms; localise country list"
       git push origin master
