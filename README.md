# **RZERVA.COM**

An online platform that connects travelers seeking an affordable and friendly place to stay with homeowners who have a spare room.

### **Running the App**

python run.py

### **Softwares & Packages**

- Python
- Html
- Bootstrap
- Javascript
- CSS
- Jinja 2
- Flask
- Sqlite3
- Docker
- Gunicorn
- Supervisor
- Ngynx server

### **Features**

- Html pages
- Floating button to access user profile
- User Dashbord
- User authentication system
- Password reset with secure cookies
- Email Notification
- Admin Dashbord
- Add Room listings
- Update room listings
- Delete room listing
- Add room images
- Add room services and amenities (Room extra)
- Room reviews
